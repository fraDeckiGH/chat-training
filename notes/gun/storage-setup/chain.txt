paginate using 2+ columns

how do I paginate using 2+ columns w/ "pagination-chain setup"? 
am I able w/ 'flat' setup?

it's possible w/ both setups, but w/ both setups share the same flaw.
example:


let's say we want the following sorting

sorting (top=priority): 
date ascending
size descending
seeds ascending

> we traverse File/date chain
sorting for 'date' field is already done for us by the chain itself

> comparing elems in each cluster
a cluster example: "File/date/2019-06-20T11:40:16.301Z"

for each node cluster we grab all the entities in that cluster
and compare (thus sorting) based on the remaining fields: size, seeds


> FLAW: we need to .get() all elems in each cluster!

let's say the node "File/date/2019-06-20T11:40:16.301Z"
has got "count: 400" that means I have to grab all 400

while I might need just... I dunno: 3?
